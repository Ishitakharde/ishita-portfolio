# Ishita Kharde — Software Engineer Portfolio

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Customize
- Update the LinkedIn URL in `src/main.jsx`.
- Add real GitHub repository URLs for projects where available.
- The NatWest-tailored resume is already included in `public/`.

## Build for deployment
npm run build

The project is Vite + React and can be deployed to Vercel, Netlify, or GitHub Pages.
